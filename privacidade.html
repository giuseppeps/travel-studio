Política de Privacidade

Atualizada em 21 de novembro de 2026.

O que é o Travel Studio

O Travel Studio é uma ferramenta de uso próprio, que roda no computador do autor e publica vídeos dele nos canais dele no YouTube, no Instagram e no Facebook. Ela não é oferecida ao público.

Dados acessados

Com a autorização do dono de cada canal, a ferramenta usa as APIs oficiais (YouTube Data API, Instagram Graph API e Facebook Graph API) apenas para:

  • identificar o canal, a conta ou a Página autorizada (nome e identificador);
  • enviar vídeos e seus textos (título, descrição, legenda) para esses canais;
  • ler o estado e o link das publicações feitas pela própria ferramenta.

Não são lidos dados de outros usuários, seguidores, mensagens ou contatos.

Armazenamento

Os tokens de acesso e o registro das publicações ficam só no computador do autor. Nada é enviado a servidores próprios nem compartilhado com terceiros, além das próprias plataformas onde os vídeos são publicados.

Remoção

A autorização pode ser revogada a qualquer momento nas configurações de cada plataforma:

  • Google: myaccount.google.com/permissions
  • Facebook e Instagram: Configurações > Integrações comerciais / Apps e sites

Ao revogar, os tokens guardados deixam de funcionar e podem ser apagados do computador do autor.

O uso de dados obtidos das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.
